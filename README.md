# Miguel Rodriguez

### Analytics · Business Intelligence · Automation

I build tools that turn business data into clear comparisons, dependable reports, and repeatable workflows. My work combines Python and SQL analysis with interactive dashboards, spreadsheet validation, and document automation.

I care about making results easy to inspect: where a number came from, how it was calculated, and what a reviewer needs to know before acting on it.

## How I work

- **Trace the result.** Keep calculations, source notes, and reporting assumptions visible.
- **Validate before reporting.** Check required fields, duplicates, counts, and reconciliation.
- **Automate repeatable steps.** Reduce manual handling while retaining review points.
- **Make the handoff useful.** Include runnable examples, documentation, and outputs people can inspect.

**Tools represented here:** Python, SQL, PostgreSQL, SQLite, TypeScript, FastAPI, Power Automate, Power BI, Power Query, Power Apps, SharePoint, Excel, and PowerPoint automation.

The public repositories include independent tools and portfolio adaptations. Demonstration data is synthetic unless a repository explicitly identifies a historical public-source example. Each project's README explains its scope, setup, and limitations.
